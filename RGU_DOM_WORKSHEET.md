# Week 4 Activity 1 — Inspecting the RGU website with DevTools

This activity must be completed against the live RGU website in a browser. The structure and copy can change, so do not guess the values.

## Steps

1. Open <https://www.rgu.ac.uk> in Chrome.
2. Open DevTools by right-clicking the page and selecting **Inspect** (or press `F12`).
3. Activate the element picker and select the **Search All Courses** button on the page. If the page layout has changed, locate the same control by its visible label.
4. In the right-hand **Properties** panel, find the selected element's `innerHTML` value. Copy the value exactly as displayed.
5. Find `parentElement` and record the parent element. If the DevTools panel displays an expandable object, open it and note the tag name and useful attributes.
6. Record the browser date and add a screenshot or a short evidence note so the observation can be reproduced.
